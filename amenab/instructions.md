you have a function that maps an infinite binary tree to 0, 1. you can think of it as of a function that maps numbers to Z/2 (numbers 0,1). 

Since each number is a sequence of bits (with maybe some zeroes in front) and this sequence of bits is a path in a tree from its start (0 go left, 1 go right). 

now there are two transformations of this tree, a and b. we define them recursively. a(0v) = 0v, a(1v) = 1b(v), b(0v) = 1v, b(1v) = 0a(v). 

Your goal is to find such a function f from this tree to Z/2 so that if you take a large chunk of the group generated by a, b (for example, just consider all words of length <= k), then the Z/2 span of this function f by this set of elements is o(k) dimensional. You can try to start with finite approximations of f.
